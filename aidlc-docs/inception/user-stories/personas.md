# User Personas — Mock Interview Platform

## Persona 1 (Primary): 林可 — 在校大四学生（秋招求职者）

![Primary]

**基本信息**
- **姓名**: 林可
- **年龄**: 22
- **身份**: 计算机专业大四学生
- **地区**: 一线城市高校
- **技术熟练度**: 高（熟悉 Web 工具、愿意尝试新产品）

**背景**
- 目标 2026 年秋招进入头部互联网或硬件公司（字节、腾讯、某公司等）
- 有 2 段实习经历，简历内容中等
- 参加过 1-2 次真实面试，但紧张表现不佳
- 晚上宿舍 / 图书馆备战面试

**目标 (Goals)**
1. 练习语音表达能力，克服面试紧张
2. 获得针对**目标公司风格**的定制化模拟
3. 看到具体、可操作的改进建议（不要空泛的"多练习"）
4. 追踪自己多次练习的进步
5. UI 好看，自己愿意推荐给同学

**痛点 (Pain Points)**
- 找不到真人面试官陪练，同学互相面试水平参差
- 看面经只能学到题目，学不到"如何回答"
- 录音自己听很尴尬，没有外部专业评价
- 通用面试工具的问题和目标公司风格不匹配

**期望体验**
- 打开即用，不要复杂注册（MVP 无认证符合需求）
- 面试过程沉浸感强，像真实面试
- 评估报告像**职业教练**给的反馈，具体而有温度
- 视觉吸引（对标 Linear / Notion 这种产品感）

**技术偏好**
- 浏览器：Chrome / Safari 最新版
- 设备：MacBook（主要）/ Windows 笔记本
- 网络：宿舍 Wi-Fi 或校园网

**使用场景**
> 深夜在宿舍，戴上耳机，花 45 分钟做一场"字节跳动后端工程师"的模拟行为面试，结束后看评估报告到 1 点，第二天再约一场。

**MVP 核心诉求（映射到需求）**
- FR-1.1/1.2/1.3：按公司/岗位定制
- FR-2.1/2.2：沉浸式语音面试 + 严格模式（真实感）
- FR-3.1/3.2：多维度评估 + 理想范答（学习模板）
- FR-4.1/4.2：记录回放（自我复盘）
- FR-4.3：导出 PDF（整理成复习资料）

## Persona 2 (Secondary — Beta): 陈老师 — 平台管理员

**基本信息**
- **姓名**: 陈老师
- **身份**: 产品运营 / 校企合作项目负责人
- **技术熟练度**: 中

**背景**
- 负责平台日常运营
- 需要监控用户使用情况，识别产品问题
- 与学校就业指导中心合作，提供使用数据报告

**目标**
1. 查看所有用户的面试记录，识别系统问题或质量异常（如 AI 评分偏差）
2. 管理题库和公司风格数据（添加/编辑/下架）
3. 查看平台使用统计（DAU、面试数、完成率、用户留存）

**痛点**
- 没有后台时无法排查用户反馈的问题
- 无法统计哪些公司风格用得多、哪些没人用

**MVP 说明**
- **陈老师的 stories 在 Beta 阶段才写**，本文档仅定义 persona 供参考。
